# 项目范围与安全边界

## G1 Navigation

- 输入包括 Unitree 状态、里程计和 Mid360 点云。
- 数据经过状态适配、里程计标准化和点云到 LaserScan 转换后进入 SLAM Toolbox 与 Nav2。
- 导航控制链包含路径规划、局部控制、速度平滑和 Collision Monitor。
- 最终运动输出经过速度限幅、超时保护、有限值检查和运动开关控制。
- 公开配置默认不向机器人发送运动指令。

## B2 Navigation

- 输入包括 SportModeState 和 RoboSense 点云。
- 数据经过里程计适配、点云转发和 LaserScan 转换后进入 SLAM Toolbox 与 Nav2。
- GPU-MPPI 负责候选轨迹生成与控制量计算，速度平滑器和 `b2_walk` 负责执行边界。
- `b2_walk` 默认关闭物理运动，并提供速度限幅、有限值检查和 watchdog。
- 公开仓库中的实验结果用于说明算法行为，不代表真实 B2 动力学性能。

## G1 Voice Interaction

- G1 ASR 负责语音识别，文本处理模块负责清理、唤醒和去重。
- 命令路由将输入分为普通对话、白名单手臂动作、有限时长前进和停止命令。
- 普通对话使用本地 Ollama 模型，回答通过 G1 TTS 播报。
- 机器人动作由本地固定白名单控制，不执行模型生成的任意机器人函数。
- 行走默认关闭，启用后仍受速度、持续时间和停止保护约束。

## 公开内容边界

本仓库公开项目源码、配置示例、架构说明和功能文档；不包含真实 API Key、私有模型、真实场地图、rosbag、设备网络配置、构建产物或未经确认可再分发的第三方二进制库。

所有真机运动均需要现场安全检查、遥控器或硬件急停。应用层停止逻辑不能替代硬件急停。
