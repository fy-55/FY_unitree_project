# 源码边界与发布说明

## 本仓库新增内容

`g1_voice_interaction/` 是作品集中的独立语音项目，包含：

- 正式 G1 语音交互 C++ 源码副本和独立 CMake 构建入口
- 本地 Ollama 启动脚本与不含密钥的配置模板
- 项目定位和功能介绍
- 正式模块与数据流说明
- 依赖、编译、测试和真机复现步骤
- 源码归属、密钥和第三方组件发布边界

## 语音项目内容

关键入口为 `example/g1/audio/g1_audio_client_test.cpp`，核心模块位于 `example/g1/voice_chat/`。本目录保存正式语音主线的源码副本。

## 公开内容边界

以下内容不属于公开项目：

- `build/`、本机构建产物和缓存
- `scripts/*.env`、任何 API Key 或私有模型配置
- Ollama 模型文件、音频采集文件和真实场地数据
- 未获得再分发许可的 SDK、机器人模型和第三方库
- 原始工作区中的旧实验代码

## 证据表述原则

文档中的“支持”“设计为”“可复现”描述代码能力和流程，不等同于已经完成真机验证。逻辑测试、模型接口测试、仿真测试和真机测试具有不同的证据强度。
