# 功能介绍

## 1. 语音对话闭环

G1 通过自带 ASR 获取中文语音文本，程序完成文本清理和唤醒词判断后，将问题交给本地 Ollama 模型。模型返回的回答再通过 G1 TTS 播报。默认接口为 `http://127.0.0.1:11434/v1/chat/completions`，示例模型为 `qwen3:8b`。

云端模型配置和启动脚本不属于本 GitHub 项目。

## 2. 唤醒与文本处理

- 默认唤醒词为 `小贝同学`。
- 支持“唤醒词 + 命令”同句说出。
- 也支持先说唤醒词，再在约 8 秒窗口内说命令。
- 两秒内重复的 ASR 文本会去重。
- 消息队列有界，网络或模型变慢时不会无限积压旧命令。

## 3. 命令路由

文本命令在本地分为四类：

| 类别 | 行为 |
| --- | --- |
| 普通问题 | 请求大模型并调用 TTS 播报 |
| 手臂动作 | 匹配本地白名单后发送固定动作 ID |
| 前进 | 仅在显式开启后，以限制速度和持续时间调用 Move |
| 停止 | 发送 StopMove，并执行必要的复位动作 |

大模型只负责普通对话，不获得直接调用机器人 API 的权限。新增动作应先加入本地路由白名单。

## 4. 当前动作白名单

- 胸前挥手：动作 ID 25
- 鼓掌：动作 ID 17
- 右手放胸口：动作 ID 33
- 举右手：动作 ID 23
- 拒绝动作：动作 ID 22
- 握手：动作 ID 27
- 停止并复位：`StopMove()` 与动作 ID 99
- 向前走两步：按速度和时间近似，不是精确步数控制

## 5. 安全保护

- 行走默认关闭，只有 `G1_ENABLE_WALKING=1` 才允许执行。
- 速度限制在 `0.05` 至 `0.30 m/s`，持续时间在启动配置中校验。
- 每条 Move 指令都是有限时长，并在结束时发送 StopMove。
- 运动中说“停止”或“停下”无需再次说唤醒词。
- 错误、退出和语音停止路径都会尝试停止运动并释放手臂。
- 真机前方必须空旷，并始终保留遥控器或急停。

语音停止是应用层保护，不等同于硬件急停。
